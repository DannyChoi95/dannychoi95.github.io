개인정보처리방침

이 방침은 English DB Dev의 합성 데이터 파일럿과 공개 안내 사이트에 적용됩니다.

Google에서 읽는 정보와 사용 목적

파일럿은 drive.metadata.readonly로 Google Drive 파일 메타데이터를, spreadsheets.readonly로 Google Sheets 데이터를 읽습니다. Google 권한 자체가 한 파일로 제한되는 것은 아니며, 파일럿은 지정된 합성 스프레드시트 한 개만 수집하도록 설정합니다. 읽은 정보는 원본 복원, 해시 검증, CSV V2 변환, 중복·충돌 확인 및 검토 대기에 사용합니다.

처리 및 저장

Google API 요청은 Cloudflare 개발용 Worker에서 처리합니다. 원본과 변환 결과의 본문은 AES-256-GCM으로 암호화해 Cloudflare Durable Object의 SQLite에 보관합니다. 파일 식별자·버전·처리 상태·해시 등은 검증과 중복 판정에 사용합니다. 인증정보와 암호화 키는 Worker의 비밀 설정에 별도로 보관합니다. 비공개 진단에는 처리 결과와 건수를 기록합니다. Google API에서 받은 정보의 사용과 이전에는 Google API 서비스 사용자 데이터 정책의 제한된 사용 요건을 적용합니다.

보존, 삭제 및 연결 해제

현재 자동 삭제 기한과 개별 사본 삭제 기능은 제공하지 않습니다. 합성 전용 저장소의 전체 초기화는 격리된 시험 환경에서 검증했으며, 실제 적용은 대상과 영향 범위를 확인하고 별도로 승인받는 수동 절차입니다. 초기화는 해당 저장소의 현재 데이터에만 적용됩니다. Google 원본과 별도 진단 로그는 그대로 남으며, Cloudflare의 시점 복구 기능으로 최근 30일 이내의 삭제 전 상태가 복원될 수 있습니다.

Google 계정의 서드 파티 연결 설정에서 접근 권한을 철회할 수 있습니다. 철회 후에도 이미 저장된 사본은 별도로 관리됩니다.

안내 사이트 방문

이 사이트는 방문자용 입력 양식이나 자체 분석 도구를 사용하지 않습니다. 호스팅 제공자인 GitHub는 보안을 위해 방문자의 IP 주소를 기록합니다. 자세한 내용은 GitHub 개인정보처리방침을 참고하세요.
